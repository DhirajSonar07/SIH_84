# SIH_84

The React + Vite frontend lives in `frontend/`.

## Start the frontend

```powershell
cd frontend
pnpm install
pnpm dev
```

Open the local URL printed by Vite. The default port is `8443`.

## Useful commands

```powershell
cd frontend
pnpm build
pnpm preview
pnpm format
```


backend start command
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
